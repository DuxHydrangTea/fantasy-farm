# Game code reset — 2026-10-15

The previous game implementation has been removed so development can start again.

- All project scenes, including scenes generated by setup scripts, were removed.
- Gameplay scripts, their UID sidecars, and 88 custom-script resource files were removed.
- Source art, fonts, built-in Godot resources (AtlasTexture, SpriteFrames, TileSet,
  Theme), addons, project settings, and AI skills were preserved.
- Asset setup tools and their input data remain in `tools/setup/`.
  `tools/setup/merge_tilesets.gd` also remains as a TileSet setup tool.
- The obsolete generated `docs/object_scenes_index.json` was removed. Running
  `tools/setup/setup_object_scenes.gd` will regenerate the object scenes and index.
- `run/main_scene` and the old `CursorController` autoload were removed from
  `project.godot`. Choose a new main scene when the rewrite has one.

`tools/setup/legacy/create_animal_resources.gd` is retained for reference only.
Its custom gameplay classes were removed at the user's request; `.gdignore`
excludes it from Godot imports until its dependencies are redesigned.

The remaining setup scripts were preserved without regenerating or overwriting
their existing resource output.

Verification: all 624 retained `.tres` resources have existing external file
dependencies, and none reference a custom script. The crop setup, animal frame
setup, object scene setup, and TileSet merge script passed Godot MCP script checks.
Full headless editor import could not complete because the local Godot Mono
executable failed to initialize its editor directories and .NET assemblies.

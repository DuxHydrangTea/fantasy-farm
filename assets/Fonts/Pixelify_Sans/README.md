# Pixelify Sans

Main UI font, downloaded from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/pixelifysans

Specimen: https://fonts.google.com/specimen/Pixelify+Sans

The bundled variable TTF is licensed under the SIL Open Font License; see OFL.txt.
The project theme uses resources/ui/pixelify_sans.tres. Mouse Meadow, already
bundled in this project, supplies Vietnamese characters absent from Pixelify Sans.
